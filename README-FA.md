# MEASUR-FA (CEP_MEASUR)

نسخه‌ی فارسی‌سازی‌شده‌ی MEASUR (دوزبانه فارسی/انگلیسی) برای ویندوز.

- مبنا: [ORNL-AMO/AMO-Tools-Desktop](https://github.com/ORNL-AMO/AMO-Tools-Desktop) نسخه‌ی v1.10.0 (مجوز MIT، فایل `LICENSE` حفظ شده است)
- ماژول‌های اولویت‌دار: بخار (SSMT) و هوای فشرده

## ساخت فایل نصب ویندوز
در تب **Actions** گزینه‌ی «Build Windows installer» را اجرا کنید (Run workflow). پس از پایان، فایل `.exe` در بخش Artifacts همان اجرا قرار می‌گیرد. همچنین با هر push به شاخه‌ی main (که فایل‌های src یا package تغییر کرده باشد) به‌طور خودکار اجرا می‌شود.

## وضعیت
- [x] کد مبنا منتقل شد و مسیر ساخت خودکار فایل نصب ویندوز اضافه شد
- [x] زیرساخت دوزبانه (سوئیچ فارسی/انگلیسی بالای صفحه + راست‌به‌چپ برای فارسی) — فایل‌های ترجمه: `src/assets/i18n/en.json` و `fa.json`
- [~] ترجمه‌ی ماژول بخار (SSMT): منوی اصلی، تب‌ها، نوار بالا، صفحه‌ی «تنظیمات ارزیابی»، صفحه‌ی خوشامدگویی ترجمه شده؛ بقیه‌ی صفحه‌های داخل گام‌های Operations/Boiler/Header/Turbine و گزارش هنوز ترجمه نشده‌اند
- [~] ترجمه‌ی ماژول هوای فشرده: منوی اصلی، تب‌های Setup/Assessment، نوار بالا، صفحه‌ی «مبانی ارزیابی» ترجمه شده؛ بقیه‌ی صفحه‌های Inventory/Day Types/System Profile/End Uses و گزارش هنوز ترجمه نشده‌اند

### نکته‌ی فنی درباره‌ی ساخت در CI
بسته‌های `@ngx-translate/core` و `@ngx-translate/http-loader` به `package.json` اضافه شده‌اند ولی چون این محیط به رجیستری npm دسترسی نداشت، `package-lock.json` به‌روزرسانی نشده است؛ به همین دلیل workflow از `npm install` به‌جای `npm ci` برای نصب ریشه استفاده می‌کند (در GitHub Actions که دسترسی کامل اینترنت دارد مشکلی ندارد، ولی قطعیت نسخه‌ها را کمی کم می‌کند). پس از اولین بیلد موفق، بهتر است `package-lock.json` به‌روز و commit شود.
